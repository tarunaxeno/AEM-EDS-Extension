Projects

Add each project once. Needed for the Universal Editor link and for production / custom domains. Preview and Live links work without any setup.

Automatic Universal Editor link

Optionally ask the Adobe Admin API for the exact editor URL of the page you are on. Needs permission for admin.hlx.page and works best while you are signed in to AEM.

My links

One per line: Label | URL. You can use {org}, {site}, {ref}, {path} and {host} in the URL.

Keyboard shortcuts

Alt+Shift+L switches the current page between Preview and Live. Alt+Shift+E opens it in the Universal Editor. To change them, open brave://extensions/shortcuts (or chrome://extensions/shortcuts) in the address bar.
